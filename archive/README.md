# Archived files

These files were moved out of the public website during the 7 October 2026 audit fixes. They remain recoverable here.

- `unused-public/audio/`: superseded Burst Down previews. Their old web paths redirect to the current v3 preview.
- `unused-public/`: unused artwork and starter SVG assets. No current application references were found.
- `legacy-tooling/`: the stale pnpm lockfile and workspace configuration. This project now uses npm and `package-lock.json` consistently.

This folder is not copied to the public build. Restoring a file to `public/` would make it publicly accessible again.
